# Privacy Policy
_Last updated: September 27, 2026_

Index Event Manager ("the bot") runs community events for the card-collecting bot **Index** in
The Hangout Discord server (discord.gg/thehangout). This page explains what data the bot uses
and why.

## What we collect

- **Index roll and claim results.** In the one channel set up for the event, the bot reads the
  messages the Index bot posts. From them it records: the Discord user ID of who rolled or
  claimed, the time, the roll type, and for claims the card name, rarity, wishlist tier, print
  number and the claim line as Index wrote it.
- **Event activity.** Items you earn, buy, open or trade (vouchers, keys, chests, boosts), quest,
  bounty and daily-reward progress, and your profile customization (theme, effects, bio).
- **Commands.** Messages starting with the bot's prefix (for example `xeinv`) are read so the
  bot can reply. During a trade, the two traders' typed offers (like "5 roll voucher") are read
  to update the trade. These messages are **not stored**.

We do **not** read, store or analyze any other messages, and we don't collect email addresses,
IP addresses or payment details.

## How we use it

Only to run the event: leaderboards, player stats, giveaway eligibility, the event shop, chests,
quests, trading and profile cards. We don't sell or share the data, and we don't use it for ads.

## Where it's stored

In a private database on our own server (Microsoft Azure). Only the bot's operators can
access it.

## How long we keep it

While the event runs. Server admins can delete a player's event data (`/resetuser`) or wipe the
whole roll history (`/reset`) at any time, and everything is deleted when the bot is retired.

## Your choices

Ask a server admin, or contact us below, to have your event data deleted. If you don't want your
Index rolls counted, roll outside the event channel.

## Contact
